# Workflow to update the website

## Add event

  1. Open the BELFORS repository on GitHub.
  2. Open assets/images/events/.
  3. Select Add file → Upload files and upload the event image.
  4. Choose Create a new branch for this commit and start a pull request. GitHub creates the branch automatically.
  5. While on the new branch, open js/events-data.js and select the pencil icon.
  6. Copy an existing event block and update its unique ID, status (upcoming or past), title, date, image filename, image description, summary, details, and optional links.
  7. The event’s position in the file determines its display order.
  8. Select Commit changes and commit to the same branch.
  9. Create a pull request into main.
